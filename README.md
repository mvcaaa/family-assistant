# Семейный ассистент в Telegram

Шлюз пускает в переписку только номера из списка и не отдаёт токен бота. Чужой чат и чужая заметка в обычный запрос не попадают. Покупка, бронь, письмо, удаление, правка памяти и заход на сервер ждут одноразовую кнопку владельца. Кнопка живёт 10 минут и подтверждает одно действие.

Режим `bot` будит Grok Bot вебхуком. Ответ списывается из недельного лимита подписки SuperGrok. Режим `api` зовёт `api.x.ai` и платится отдельно. Телефонию, оплату и отправку писем программа не делает: после «да» ассистент может подготовить черновик.

Круглосуточный вариант не требует VPS. Шлюз работает на машине, которая и так включена дома, и выходит в интернет через Cloudflare Tunnel.

## Что нужно заранее

- Telegram и бот, созданный в [@BotFather](https://t.me/BotFather).
- Подписка, в которую входит Grok Bot: SuperGrok, X Premium / Super / Ultra или подходящий план Cursor. Режим `api` вместо этого требует ключ на [console.x.ai](https://console.x.ai).
- Домен в Cloudflare. Отдельный сервер в облаке не нужен.
- Хост, который не засыпает и умеет Docker. Ниже это TrueNAS SCALE и его custom app. Подойдёт и другой Docker на той же сети, что и `cloudflared`.
- Номера семьи в международном виде, без плюса. В список попадает номер, привязанный к Telegram, а не любой другой номер того же человека. `OWNER_PHONE` — один из этих номеров. Только он нажимает кнопки.
- Секреты вне git: файл `.env` с правами `600` или менеджер паролей. В репозитории есть шаблон ссылок `deploy/env.op.tpl` для 1Password.

Один процесс с одним токеном Telegram. Второй экземпляр заберёт обновления себе, и ответы пропадут.

## Локальная проверка

Нужен Python 3.11 или новее.

1. В BotFather: `/newbot`, затем `/setjoingroups` → Disable. Токен сохрани. В группу шлюз всё равно не отвечает: он принимает только личные чаты.
2. Скопируй `deploy/env.example` в `.env`. Для первой проверки поставь `ASSISTANT_BACKEND=echo`.
3. Запусти:

```bash
cd family-assistant
PYTHONPATH=src python3 -m family_assistant --env .env
```

4. С телефона владельца: `/start` и «Поделиться номером». Потом то же самое с каждого номера из списка. Чужой номер получает отказ.
5. Напиши фразу. В режиме `echo` ответ начинается с «Эхо:». Останови процесс через Ctrl-C.

Правила для модели лежат в `DATA_DIR/rules.md`. Файл создаётся при первом запуске, его можно править. Память, версии заметок и кнопки лежат в `DATA_DIR/assistant.sqlite`.

## Как этим пользоваться

Пиши текстом в личный чат с ботом. В режиме `bot` голосовые не распознаются: шлюз просит написать словами. Голос понимает только режим `api`.

- `/memory` показывает заметку только этого человека.
- `/whoami` показывает, узнал ли бот номер.
- Владелец пишет `ревизия` или `/review`. В этот запрос попадают заметки семьи, и модель может предложить замену. Пока кнопка не нажата, старый текст остаётся, а прошлая версия сохраняется. Чужие переписки владельцу в Telegram не отдаются.
- Раз в `REVIEW_DAYS` дней (по умолчанию 7) бот напоминает владельцу сверить память: имена и число символов, без текстов заметок. Сам ничего не удаляет.
- Просьба купить, забронировать, написать кому-то, удалить или зайти на сервер превращается в кнопку в чате владельца. «Нет» и просрочка ничего не меняют. Повторно та же кнопка не срабатывает.

Общие правила редактируй в `rules.md`. Личные факты модель дописывает сама, короткой строкой, и только в заметку того, с кем сейчас говорит.

Каждый человек открывает бота у себя. Семейная группа не используется.

## Self-hosting без VPS

Шлюз и `cloudflared` живут в одном приложении. Туннель публикует одно имя, например `aino-bot.example.com`, и отдаёт его контейнеру `family-assistant` на порт `8787`. Порт на роутере и на хосте открывать не нужно: коннектор сам держит исходящее соединение с Cloudflare.

Один контейнер `cloudflared` обслуживает один туннель. В туннеле может быть много имён. Отдельный коннектор внутри каждого приложения не обязателен. Ниже коннектор стоит рядом со шлюзом, потому что маршрут ссылается на имя сервиса `family-assistant`.

### 1. Секреты

Собери `.env` по `deploy/env.example` или так:

```bash
op inject -i deploy/env.op.tpl -o .env
chmod 600 .env
```

Для режима подписки в файле должны быть `ASSISTANT_BACKEND=bot`, токен Telegram, номера, `GATEWAY_PUBLIC_URL=https://aino-bot.example.com` без слэша на конце, `GROK_BOT_WEBHOOK_URL` и `GROK_BOT_WEBHOOK_KEY`. Последние два появляются на шаге 4. Внутри контейнера `GATEWAY_HOST=0.0.0.0`, `DATA_DIR=/data`.

Ключ вебхука — Bearer, обычно с префиксом `crsr_`. Секрет подписи `whsec_` этот шлюз не проверяет.

### 2. Туннель

Создай туннель там, где уже заводишь остальные: Terraform или панель Cloudflare. Коннектор ещё не обязан работать.

Публичный hostname:

- имя `aino-bot.example.com`;
- сервис `http://family-assistant:8787`;
- всё остальное — `http_status:404`;
- DNS — proxied CNAME на `<tunnel-id>.cfargotunnel.com`.

`localhost` в сервисе не подходит: для `cloudflared` это был бы он сам. На этом имени не включай Cloudflare Access и Bot Fight Mode. Grok Bot приходит обычным POST с пропуском и не проходит страницу входа.

### 3. Приложение на TrueNAS

В Apps создай custom app. Оба сервиса — в одном compose, без проброса портов на хост. Каталог данных, например `/mnt/pool/family-assistant/data`, смонтируй в `/data`. Образ публикуется из этого репозитория: `ghcr.io/mvcaaa/family-assistant:latest` (`linux/amd64` и `linux/arm64`).

```yaml
services:
  family-assistant:
    image: ghcr.io/mvcaaa/family-assistant:latest
    restart: unless-stopped
    env_file:
      - /mnt/pool/family-assistant/family-assistant.env
    volumes:
      - /mnt/pool/family-assistant/data:/data

  cloudflared:
    image: cloudflare/cloudflared:2026.10.1
    restart: unless-stopped
    command: ["tunnel", "--no-autoupdate", "run"]
    env_file:
      - /mnt/pool/family-assistant/cloudflared.env
```

В `cloudflared.env` одна строка `TUNNEL_TOKEN=...`, права `600`. Токен коннектора показывает Cloudflare после создания туннеля. Имя сервиса `family-assistant` менять нельзя: его ждёт маршрут туннеля.

Проверка снаружи, когда оба контейнера запущены:

```bash
curl -sS https://aino-bot.example.com/health
```

Ответ `{"ok": true}` значит, что туннель дошёл до шлюза. Пока контейнера шлюза нет, Cloudflare отвечает `502`.

### 4. Routine в Grok Bot

Нового бота в Telegram для этого шага не нужно. В десктопном приложении Grok создай отдельного бота, чтобы семейные сообщения не попали в личные дела.

1. В боковой панели нажми **+** и **Create new Bot**. Имя, например, `Aino`.
2. В чат этого бота вставь текст из `deploy/grok-bot-routine.md`, начиная со строки «Ты семейный ассистент». Две строки над ней в инструкцию не входят. Попроси создать routine с триггером webhook, без расписания, и оставить её включённой.
3. Нажми имя бота вверху чата, открой **Routines**, затем эту routine.
4. Скопируй **POST to** и **key**. В чат и в git их не клади. Допиши их в `.env` и перезапусти приложение.

Каждое сообщение семьи будит одну routine. Шлюз сразу пишет «Передал. Ответ придёт в этот чат.» Текст появляется, когда Bot вызовет шлюз с пропуском. Пропуск действует `PASS_TTL` секунд (по умолчанию 15 минут), открывает один чат и одну заметку. Ответ HTTP `200` на вебхук значит, что запуск принят, а не что ответ уже готов. У одной routine до 200 запусков в час.

### 5. Первое сообщение

С телефона владельца открой бота, нажми `/start`, поделись номером и напиши обычную фразу, например «Привет. Как тебя зовут?». Сначала придёт «Передал», затем ответ.

Остальные люди делают то же самое в личном чате. Их номера должны уже лежать в `ALLOWED_PHONES`. Номер, которого нет в списке, бот не пускает.

## Docker на компьютере

Пуш в `main`, который меняет образ, собирает обе платформы и публикует `ghcr.io/mvcaaa/family-assistant` с тегами `latest` и `sha-<commit>`. Секреты в образ не попадают.

Локальный `docker-compose.yml` публикует порт только на `127.0.0.1`. Это проверка на ноутбуке, не публичный адрес.

```bash
op inject -i deploy/env.op.tpl -o .env
chmod 600 .env
docker compose up -d
curl -sS http://127.0.0.1:8787/health
```

## VPS

Тот же контейнер можно поставить на VPS, если домашней машины нет. Приём Telegram идёт долгим опросом и сам по себе открытого порта не требует. Ответ Bot требует https-адрес шлюза: Cloudflare Tunnel или обратный прокси на `127.0.0.1:8787`. Unit для запуска без Docker лежит в `deploy/family-assistant.service`.

```bash
sudo useradd --system --create-home --home-dir /var/lib/family-assistant --shell /usr/sbin/nologin familybot
sudo mkdir -p /opt/family-assistant
sudo cp -a src deploy /opt/family-assistant/
sudo cp deploy/env.example /etc/family-assistant.env
sudo chmod 600 /etc/family-assistant.env
sudo chown familybot:familybot /var/lib/family-assistant
sudo cp deploy/family-assistant.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now family-assistant
```

В `/etc/family-assistant.env` поставь `DATA_DIR=/var/lib/family-assistant`. `Restart=always` поднимает процесс после падения. В логах нет текста сообщений и нет токена.

## Проверка без Telegram

```bash
cd family-assistant
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Тесты проверяют допуск по номеру, изоляцию чатов и заметок, одноразовость кнопки и то, что токен бота не попадает в запрос к модели.
